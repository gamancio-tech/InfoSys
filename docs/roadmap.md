# Roadmap

Público e de alto nível. Detalhes de priorização comercial ficam fora do repositório.

## Fase 0 · Fundações (antes de codar funcionalidades)

- [✔] ADRs 0001–0009 decididas
- [✔] Prova de conceito de runtime (Node vs Bun) e integrações críticas
- [✔] Garantir atualização da documentação por meio de skills e revisão com IA
- [✔] Monorepo, CI, lint, testes, gitleaks
- [ ] Better Auth + organizations + isolamento por tenant com teste
- [ ] Deploy de "hello world" em produção (domínios, cookies, Sentry)

## Fase 1 · MVP vendável

- [ ] Clientes (endereços, anotações, equipamentos)
- [ ] Agenda (tipos configuráveis, conflitos, responsável)
- [ ] Catálogo de produtos e serviços
- [ ] Orçamentos + PDF com modelo do sistema
- [ ] Orçamento aprovado → agendamento
- [ ] Planos de manutenção + avisos (e-mail/push ao prestador)
- [ ] Histórico do cliente
- [ ] Migração dos dados da Infotell
- [ ] PWA instalável + leitura em cache

## Fase 2

- [ ] Faturas e cobrança (Pix/boleto via gateway)
- [ ] Estoque (entrada, saída, mínimo)
- [ ] Dashboard financeiro e despesas
- [ ] Exportação CSV/Excel padronizada
- [ ] Planos, trial e cobrança do SaaS

## Fase 3

- [ ] Modelo Word com placeholders
- [ ] Preenchimento de planilha Excel do usuário
- [ ] IA para modelo de PDF (se houver demanda)
- [ ] Avisos ao cliente final (e-mail/WhatsApp)

## Antes do primeiro cliente pagante

- [ ] Termos de uso e política de privacidade
- [ ] Backup com restauração testada
- [ ] Runbook de incidentes
- [ ] Documentação do usuário final
